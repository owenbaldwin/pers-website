# Owen Baldwin — Personal Website

A frontend-only personal portfolio and CV site built with Angular 20 and SCSS.

## Getting started

The project uses Node 20.19.5, recorded in `.nvmrc`.

```bash
nvm use
npm install
npm start
```

Open [http://localhost:4200](http://localhost:4200) after the development server starts.

## Editing the site

- Update experience and project entries in `src/app/app.ts`.
- Update page copy and contact links in `src/app/app.html`.
- Adjust design tokens and layout in `src/app/app.scss`.
- Replace `public/favicon.ico` and add a CV PDF to `public/` when ready.
- The original visual direction is stored in `design/personal-site-concept.png`.

## Commands

```bash
npm start      # Local development server
npm run build  # Production build
npm test       # Unit tests
```
